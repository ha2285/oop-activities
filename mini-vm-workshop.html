What you just watched — the seven stages

    

      
StageWho actsWhat happens

      
        
CompilejavacYour .java becomes portable bytecode (.class), not native machine code.

        
LoadClass LoadersDelegation: the request goes up to Bootstrap (core java.*), and your own classes fall to the Application loader. Loaded metadata lands in the Method Area.

        
VerifyVerifierBytecode is checked for safety before it may run.

        
ExecuteInterpreterFetch–decode–execute. new asks the Method Area for the blueprint and the Heap allocates the object; fields are written.

        
Native callJNIprintln is ultimately native — the call crosses the Java Native Interface to a native library that writes to the console.

        
OptimizeJITA method that runs often (“hot”) is compiled to native code so later calls skip interpretation and run faster.

        
ReclaimGCWhen an object is no longer reachable, the Garbage Collector marks live objects from the roots and sweeps the dead one off the Heap.

      
    

    
The teaching bytecode vs. real bytecode: our C++ engine uses friendly opcodes (NEW, STORE, DESCRIBE). Real javac emits mnemonics like new, dup, invokespecial, putfield, iadd, invokevirtual — shown in the right-hand panel above so students can compare.

🧭 What to do

      
You are building an object-oriented model of the JVM: each region of the diagram is a C++ class. Your job is to finish the parts that make objects real.


      
1 · Set up

      
    
        
  • Open mini_vm_starter.cpp in any editor.
    • 
        
  • You need a C++ compiler — g++ or clang++ — and a terminal.
    • 
      


      
2 · Fill in the TODOs

      
    
        
  1. Heap::allocate — push a new ObjectData and return its index (the object’s reference).
    2. 
        
  2. OperandStack::push / pop — the working stack of a frame.
    3. 
        
  3. Arithmetic opcodes — ADD, SUB, MUL, DIV (guard divide-by-zero) and PRINT.
    4. 
        
  4. Object opcodes — NEW (ask the Method Area, allocate on the Heap, push the reference), STORE (write a field), DESCRIBE (print the object).
    5. 
      

      
The heart of it — NEW, where the Method Area and Heap cooperate:


case NEW: {
    int classId = pc.fetch(code);
    const ClassInfo& cls = methodArea.get(classId);  // blueprint
    int ref = heap.allocate(classId, cls.name);      // allocate
    stack.push(ref);                                // push reference
    break;
}


      
3 · Build & run


g++ -std=c++17 -O2 -o minijvm mini_vm_starter.cpp
./minijvm
