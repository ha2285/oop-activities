The File Format Trials

Two ways to store data in Java — as human-readable text, or as raw binary. Four levels, ~12 minutes. Score 60%+ to earn your I/O badge.

📄 Text files

  • Characters, encoded (UTF-8)
  • Reader / Writer classes
  • Readable in any editor
  • Number 1000 → 4 chars "1000"

💾 Binary files

  • Raw bytes, no encoding
  • InputStream / OutputStream classes
  • Looks like garbage in an editor
  • An int → always 4 bytes
